# Truy vấn Cơ sở dữ liệu Quản lý Khách sạn

Dự án này chứa tập hợp các câu truy vấn cơ sở dữ liệu phục vụ báo cáo môn học Cơ sở dữ liệu, áp dụng cho bài toán Hệ thống Quản lý Khách sạn.

## Cấu trúc thư mục

Thư mục `truyvan/` bao gồm các tệp sau:
- `truyvan_MS_SQL.sql`: Bộ truy vấn viết theo chuẩn T-SQL cho Microsoft SQL Server.
- `truyvan_MySQL.sql`: Bộ truy vấn viết theo chuẩn SQL cho MySQL.
- `TRUYVAN_SQL.md`: Tài liệu tổng hợp danh sách các case truy vấn, trường hợp sử dụng và mục đích.
